# あみだくじ 🎋

ブラウザだけで動くシンプルなあみだくじアプリです。依存ライブラリなし・単一 HTML ファイルで構成されています。

**→ [ライブデモ](https://jg1lsy.github.io/amida-kuji/)**

## 機能

- **参加者を自由に設定**（2〜10名）
- **結果ラベルを自由に設定**（当選・はずれなど）
- **横棒を1本だけ追加**できる（クリックで任意の位置に）
- **アニメーション**付きでくじを引く（参加者ごとに色分け）
- 全員引き終わると**自動で結果発表**
- スマートフォン対応

## 使い方

1. 参加者名と結果ラベルを入力して「あみだを生成」
2. Canvas をクリックして横棒を1本追加（省略可）
3. 各参加者の名前ボタンをクリックしてくじを引く
4. 全員引き終わると当選者が発表される

## ローカルで使う

```
index.html をブラウザで開くだけで動作します。
```
